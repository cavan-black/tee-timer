# Store artwork provenance

Everything here is used to *advertise* the app, which is a different question
from the course photography inside it. The photos the app displays belong to the
clubs and are shown alongside those clubs' own prices; they are not ours to
market with. So store artwork uses only images we are unambiguously free to use
commercially, with no attribution obligation a store listing has nowhere to
satisfy.

## marbella-source.jpg

| | |
|---|---|
| Subject | Public beach at Marbella, immediately south of the old town |
| Source | [Wikimedia Commons — `File:Beach in Marbella.JPG`](https://commons.wikimedia.org/wiki/File:Beach_in_Marbella.JPG) |
| Author | Ypsilon from Finland (own work) |
| Licence | **CC0 1.0 Universal** — public domain dedication |
| Attribution required | No |
| Commercial use | Yes |
| Retrieved | 28 July 2026 |
| Original size | 3200 × 2400 |

CC0 was the deciding factor. Most Marbella coast photographs on Commons are
CC BY or CC BY-SA, which require visible credit — awkward on a feature graphic
and, in the case of share-alike, arguably infectious for the composite.
